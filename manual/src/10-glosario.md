<!-- ES -->
| Palabra | Significado sencillo |
|---|---|
| **Servidor** | Programa (o computadora) que atiende pedidos de otros equipos |
| **Puerto** | "Puerta" numerada de un servidor: 8080, 8096… |
| **IP / número de la laptop** | La dirección de un equipo en la red, como 192.168.1.45 |
| **localhost / 127.0.0.1** | "Esta misma computadora" |
| **Docker / contenedor** | Caja sellada donde corre un programa sin tocar el resto del sistema |
| **docker compose** | La lista de instrucciones para encender un grupo de contenedores |
| **.env** | Archivo con contraseñas y ajustes privados; nunca va a GitHub |
| **Montar un disco** | Conectarlo para que el sistema lo pueda usar |
| **ext4 / FAT32 / NTFS** | Formatos de disco (Linux / viejo / Windows) |
| **sudo** | Hacer algo como administrador |
| **Git / GitHub / git pull** | El historial del proyecto / donde vive en internet / traer la última versión |
| **DNS** | La "guía telefónica" que convierte nombres (`caciqueflix.home`) en números |
| **VLAN** | Red separada que comparte el mismo cable |
| **Firewall** | El portero que decide quién puede hablar con quién |
| **ZIM** | Formato de libro de Kiwix (como este manual) |
| **ROM / BIOS** | El juego copiado a un archivo / el programa de arranque de la consola |
| **Emulador** | Programa que imita una consola |

<!-- EN -->
| Word | Simple meaning |
|---|---|
| **Server** | A program (or computer) that answers requests from other devices |
| **Port** | A server's numbered "door": 8080, 8096… |
| **IP / laptop number** | A device's address on the network, like 192.168.1.45 |
| **localhost / 127.0.0.1** | "This same computer" |
| **Docker / container** | A sealed box where a program runs without touching the rest of the system |
| **docker compose** | The instruction list for starting a group of containers |
| **.env** | File with passwords and private settings; never goes to GitHub |
| **Mounting a drive** | Connecting it so the system can use it |
| **ext4 / FAT32 / NTFS** | Drive formats (Linux / old / Windows) |
| **sudo** | Doing something as administrator |
| **Git / GitHub / git pull** | The project's history / where it lives online / getting the latest version |
| **DNS** | The "phone book" that turns names (`caciqueflix.home`) into numbers |
| **VLAN** | A separate network sharing the same cable |
| **Firewall** | The doorman that decides who may talk to whom |
| **ZIM** | Kiwix's book format (like this manual) |
| **ROM / BIOS** | The game copied into a file / the console's startup program |
| **Emulator** | A program that imitates a console |
